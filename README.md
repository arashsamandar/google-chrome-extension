
# Very Very Light Weight Extension > Move Tabs With only ALT + arrows , ALT + BACK & ALT + Forward

> in google chrome go to `chrome://extensions` select `Load Unpacked` from the top left and choose the folder you cloned this repository to
> then in chrome://extensions/shortcuts choose it and select your shortcut key for move forward or previous on your google tabs ( websites ) that you have open .
